# Hermes Framework Reference

This directory is reserved for Hermes-based implementation planning.

- `hermes-agent/` is a local clone of `https://github.com/nousresearch/hermes-agent`.
- The clone is intentionally ignored by git and should not be modified, committed, or pushed from this repository.
- Product requirements live under `docs/product/`.
- SDK and backend implementation evidence lives under `docs/implementation/sdk/`.
