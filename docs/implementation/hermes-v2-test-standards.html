Goal guardrails

让 Hermes 做执行底座，但产品事实始终归 Mibusy 管。

这些 gate 的目的不是堆测试，而是防止开发时走偏：不让 Hermes 变成产品数据库，不让临时 helper 变成员工，不让 UI 回到 v1 的 agent control plane。

01

Product Model Invariants

防止产品退回到复杂 agent org chart。

must pass

Required checks

  • 永久员工只能由真人创建、启用、停用、复制或定制。
  • runtime helper 必须是临时且绑定 assignment。
  • agent 只能请求 delegation，不能直接创建 child assignment。
  • 跨真人协作必须变成 handoff。
  • skill 可以自动提议，但 promotion/publication 需 policy 或真人批准。

Minimum cases

agent -> create permanent staff: rejected
agent -> spawn temp helper within budget: accepted
temp helper -> spawn helper: rejected
agent -> delegate to permitted staff: accepted
agent -> delegate to unpermitted staff: rejected
agent -> request another human's work: handoff proposal
completed task -> skill proposal: pending

04

UI Product Semantics

确保 Boardroom v2 心智稳定，不回到 v1 dark control plane。

UI gate

Required checks

  • 底部 tabs 保持 今日 / 待审 / 团队 / 会议室。
  • 默认员工、定制员工、Beacon、技能、临时 helper 视觉区分。
  • 临时 helper 不能出现在 standing employee roster。
  • 任务详情 task-first，不是 org-chart-first。
  • Hermes internals 不能成为主 UI 标签。

Minimum routes

/chat       今日
/inbox      待审
/templates  团队
/observe    会议室
05

Skill and Memory Safety

让经验沉淀，但不污染公司共享知识。

knowledge

Required checks

  • 任务完成可以生成 skill proposal。
  • proposal 记录 source assignment 和 trace。
  • Beacon 或 reviewer 能 approve/reject promotion。
  • 默认系统 skill 不能被 runtime output 覆盖。
  • Desk memory 写入可以 pending approval。

Minimum cases

runtime proposes new skill -> pending version
Beacon passes skill -> eligible for promotion
Beacon fails skill -> probation/rejected
agent proposes memory -> pending or scoped write
private Desk memory -> not visible to unrelated Desk
06

Folder Sharing and Context Permissions

让真人和虚拟员工共享资料，但不把整个文件系统暴露给 runtime。

context

Required checks

  • Workspace Library、Desk Library、Assignment Workspace 权限分开。
  • Hermes 只拿 scoped assignment workspace 和 context pack。
  • agent 写 Desk memory 必须走 propose，不直接写。
  • handoff 只共享 context pack，不共享源 Desk 全量 folder。
  • temp helper 只看到 parent assignment 传入的子集。

Minimum cases

agent reads assigned context pack: allowed
agent reads unrelated Desk folder: rejected
temp helper reads parent context subset: allowed
Hermes writes assignment scratch file: allowed
Hermes writes Desk memory directly: rejected
handoff shares context pack: target Desk can read pack
handoff does not share source Desk library: rejected

09

Migration Safety

v2 schema 逐步加入，不破坏旧数据和旧验证。

DB

Required checks

  • migrations additive until planned cutover。
  • v1 tables can coexist with v2 tables。
  • default staff seed idempotent。
  • no destructive migration without backup plan。
  • missing runtime profile fails clearly。

Minimum cases

fresh DB -> seeds default staff
existing DB -> preserves sessions/templates
re-run seed -> no duplicate default staff
missing runtime profile -> clear failed assignment
10

Observability

每个 assignment 都要能解释：谁、在哪个 Desk、用哪个 runtime、为什么失败。

trace

Every assignment exposes

  • runner provider / runtime profile / model
  • assignment id / Desk id / staff id
  • parent assignment id if any
  • event sequence
  • budget/tokens if available
  • terminal status and error reason

Minimum cases

successful Hermes run -> status/message/final
failed Hermes run -> status/error/terminal failed
delegated task -> parent and child ids linked
temporary helper -> parent assignment and TTL visible
11

Definition of Done

v2 feature 完成条件，适合作为 PR checklist。

done
1. Product invariants没有破坏 Desk / staff / helper 边界。
2. Mibusy SoT产品事实不直接写进 Hermes。
3. Adapter boundaryHermes 通过 runner 或 tool bridge 接入。
4. Testspolicy 和 event mapping 有单测。
5. Smoke path有真实 smoke 或 mock fixture。
6. Hermes untouched不修改 ignored Hermes clone。
7. Verify passespnpm verify:offline 通过。
8. UI language符合 Boardroom v2 语义。
